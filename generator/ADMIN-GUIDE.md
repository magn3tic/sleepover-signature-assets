# SleepOver signatures: admin guide

Create, correct and remove SleepOver email signatures yourself, from the same
page the client uses:

**https://magn3tic.github.io/sleepover-signature-assets/pages/index.html**

## One-time setup (10 minutes)

1. **Install the font.** Double-click `Obviously-NarrowBlack.otf` (from Gabriel)
   and click *Install*. Then quit and reopen your browser. The font is licensed
   to Mag for our own computers only: don't share it or upload it anywhere.
2. **Use Chrome or Edge.** Safari can't use installed fonts on web pages.
3. **GitHub.** You need a GitHub account with access to the
   `magn3tic/sleepover-signature-assets` repository (Gabriel adds you). Then make
   a token: github.com → your photo → *Settings* → *Developer settings* →
   *Personal access tokens* → *Fine-grained tokens* → *Generate new token*:
   - Resource owner: **magn3tic**
   - Repository access: *Only select repositories* → **sleepover-signature-assets**
   - Permissions: **Contents: Read and write** and **Actions: Read**
   - Copy the token (it starts with `github_pat_`).
4. On the signatures page, click the **gear** at the top right, paste the token,
   keep *Remember on this computer* ticked, click **Save and connect**.
   An orange **ADMIN** bar appears. Each signature now has **Edit** and **Delete**.

## New signature

1. **New signature** in the admin bar.
2. Pick the region, then type the name, position, mobile, email. The office
   phone and address are filled in from the region; change them if needed.
3. The name artwork is drawn for you on the right. Check it and the signature
   preview, light and dark.
4. **Create and publish.** Wait about 2 minutes until it says **Live**.
5. **Copy link** and send it to the person so they can install their signature.

## Correct a signature

1. **Edit** on the person's card. Change what's wrong.
   - Changing the **name or position** redraws the artwork automatically.
   - Changing only phone, email or address keeps the current artwork.
2. **Save and publish**, wait for **Live**.
3. **Tell the person to install their signature again** from their link (same
   link as before). What's in their Outlook is a copy: it does not update
   itself.

## Delete a signature

**Delete** on the card, type the name to confirm. Their page and link stop
working. Emails they already sent are not affected.

## Good to know

- Leave **Mobile** or **Office phone** empty to hide that line.
- **Address**: one line per row. If you type it on one line, it's split on the
  commas for you.
- **Upload a PNG from design**: use this if design made the artwork by hand
  (same size as the others, about 115px tall).
- A long name is placed slightly smaller so it fits. That's expected.
- If publishing **fails**, nothing on the live pages changed. Open the link in
  the message and send it to Gabriel.
- Made a mistake? Just edit again. Every change is kept on GitHub and can be
  undone.
